# Samples

Runnable examples that sit beside the published `template/`.

| Sample          | Path                                   | What it shows                               |
| --------------- | -------------------------------------- | ------------------------------------------- |
| Greeting        | [`greeting/`](greeting/)               | Browser React → `google.script.run` → GAS   |
| Spreadsheet MCP | [`spreadsheet-mcp/`](spreadsheet-mcp/) | Gemini Spark → MCP Tools → Spreadsheet      |
| Contact API     | [`contact-api/`](contact-api/)         | External Web → `fetch` (CORS) → GAS Web API |

Each sample is its own package. `cd` into the sample directory before installing or running scripts.
